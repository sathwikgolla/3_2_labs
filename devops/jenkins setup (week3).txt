Create budget > select zero spend budget in template > and give budget name as My Zero-Spend Budget>give Email>click on create budget
Search for EC2 > Launch Instance> give name as your wish(Jenkins)
In Application server Select Ubuntu > Create a NewKey pair

Go to security > click on security groups> Edit inbound rule > Add rule>select type as Custom TCP> In port range give 8080 and select 0.0.0.0/0 >Save rule
